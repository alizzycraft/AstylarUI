# Position follow-up classification batch

This is a prepared review boundary, not a canonical integration or completion
claim. It replays six checked source reports into fourteen reviewed groups /
768 observations: tooltip, tabs, stepper, radio, seven static-position
measurement-stage groups, and three choice-label stacking groups.

Each source collector reauthenticates its pinned population and paired trees.
Its fresh output must equal the checked-in source report. Complete ordered case
membership is checked against the original position population. Seven groups
retain application/plugin authoring-defect classifications; seven retain the
narrow harness measurement-stage classification. The latter does **not** assert
that omitted candidate position means computed static or equivalent layout.

The batch cannot promote sort, toolbar or button-toggle inspection evidence to
a resolved classification. It does not infer a renderer cause for any group.

## Preservation boundary

`tests/material-parity/position-followup-review.mjs` requires each predecessor's
complete pinned digest and unresolved attribution. Only classification metadata
is replaced. Raw values, omitted fields, case samples, counts and all unrelated
rows remain untouched. Original metadata is retained with explicit presence
bits. Serialized validation reconstructs the full predecessor and verifies its
independent digest, preventing a new field or synthesized default from slipping
through a selected-property comparison.

The production adapter, complete capture binding, source-inventory transition
and canonical regeneration are still required. This module is deliberately not
wired into the producer while the previous batch regeneration is live. Passing
its isolated aggregation test is not conservation proof for the canonical
8,483-row report and does not supersede the full-report check.
